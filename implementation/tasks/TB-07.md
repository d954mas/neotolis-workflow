# TB-07 — BRIEF gate and complete nttask runtime lifecycle

## Goal

Complete the deterministic runtime side of `nttask`, including its protected artifact boundary.

## Dependencies

- `TB-06` committed and passing.

## Owned files

- `src/runtime/artifacts.ts`
- `src/runtime/nttask.ts`
- nttask-specific integration in `src/cli/main.ts`
- `tests/nttask/**`
- `tests/fixtures/briefs/**`

## Implementation contract

- Protect `.ntworkflow/runs/<run-id>/BRIEF.md`.
- Require one non-empty H1.
- Require exactly one non-empty `## Brief`, `## Repository context`, and `## Success` in that order.
- Allow `## Open questions` only once and only after the required sections.
- Reject other H2 sections.
- Validate BRIEF before the state commit for `phase complete nttask`.
- Successful completion enters `brief-ready`, clears phase/owner, and returns `ntgrill` as next action.
- `brief-ready` nttask re-entry is read-only.
- Invalid artifacts remain untouched for explicit user correction.
- Unicode paths, text, and URLs must round-trip without corruption.
- Cover the whole start/begin/complete/stop/cancel/re-entry sequence.

The CLI validates structure only. The skill owns semantic sufficiency.

## Acceptance

`TB-AC-07` is complete when every legal and illegal deterministic `nttask` boundary has coverage and no failure repairs artifacts or state.

## Verification

```powershell
npm run check
npm run build
node scripts/run-tests.mjs nttask
```

Required results:

- valid BRIEF advances to `brief-ready`;
- missing, duplicate, empty, out-of-order, or unknown H2 blocks completion;
- invalid BRIEF and state remain byte-for-byte intact;
- interrupted intake requires confirmation;
- brief-ready re-entry returns `ntgrill` without mutation;
- Git ignore/config fixtures remain unchanged;
- workflow runtime files never appear outside `.ntworkflow/`.

## Handoff

Report commit, complete CLI surface, BRIEF contract, verification, deviations, and blockers. Stop.
