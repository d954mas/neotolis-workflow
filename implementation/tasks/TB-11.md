## Verification

```powershell
npm ci
npm run verify
```

`verify` must run check, build, all deterministic suites, clean provider fixtures, conformance, E2E, and package verification.

Required final E2E evidence:

1. Empty invocation creates nothing.
2. First start creates only state and `runs/NT-001/` under `.ntworkflow/`.
3. Phase begin records native owner.
4. Unicode BRIEF with a URL passes the structural gate.
5. Completion enters `brief-ready` and clears owner.
6. Fresh `nttask` re-entry is read-only and returns `ntgrill`.
7. Competing owner is rejected without confirmation.
8. Confirmed cross-provider takeover succeeds.
9. Cancellation preserves the permanent run directory.
10. Corrupt state, invalid BRIEF, held lock, and partial directory are not repaired.
11. Delivery-ready replacement atomically selects the next run.
12. Claude and Codex normalized responses/filesystems match.
