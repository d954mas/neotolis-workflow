# TB-09 — Codex plugin

## Goal

Build and prove the equivalent minimal user-level Codex plugin.

## Dependencies

- `TB-07` committed and passing.
- In stable sequential execution, `TB-08` should already be committed; do not alter its files.

## Owned files

- `plugins/codex/**`
- `marketplaces/codex/**`
- the Codex branch of `src/providers/session-start.ts`
- `tests/providers/codex/**`

## Required official contracts

- <https://learn.chatgpt.com/docs/build-plugins>
- <https://learn.chatgpt.com/docs/build-skills>
- <https://learn.chatgpt.com/docs/hooks>
- <https://github.com/openai/codex/blob/main/codex-rs/app-server/README.md>

## Implementation contract

- Add `.codex-plugin/plugin.json`, `hooks/hooks.json`, and `skills/nttask/SKILL.md`.
- Invocation is `$nttask`.
- SessionStart reads native hook JSON and supplies canonical `codex:<session_id>`, cwd, and installed CLI path.
- Use `PLUGIN_ROOT` and a Windows `commandWindows` override.
- Untrusted or disabled hook must prevent workflow mutation and direct the user to `/hooks` and a fresh session.
- Use an isolated local marketplace with remote plugin merge disabled.
- Prove actual discovery with app-server `skills/list(forceReload:true)` and `hooks/list`.
- Do not emulate provider discovery, copy caches manually, or add custom-agent placeholders.

## Acceptance

`TB-AC-09` is complete when the pinned Codex CLI installs the local plugin and app-server reports its skill and hook in clean Windows/Unix fixtures.

## Verification

```powershell
npm run build
node scripts/run-tests.mjs provider-codex
```

The isolated harness must execute:

```text
codex plugin marketplace add <staged-marketplace>
codex plugin add neotolis-workflow@neotolis-local
codex plugin list --json
codex app-server
```

Expected:

- plugin is installed and enabled;
- `skills/list` returns `nttask`;
- `hooks/list` returns the plugin SessionStart hook and trust status;
- recorded payload yields exact native owner and existing CLI path;
- an untrusted-hook fixture creates no `.ntworkflow/`.

If documented installation/discovery fails on pinned Windows Codex, stop and report a blocker rather than substituting a custom scanner.

## Handoff

Report commit, marketplace path, app-server discovery response, hook evidence, verification, deviations, and blockers. Stop.
