# TB-08 — Claude Code plugin

## Goal

Build and prove the minimal user-level Claude Code plugin containing `nttask`, native session identity, and the exact runtime bundle.

## Dependencies

- `TB-07` committed and passing.

## Owned files

- `plugins/claude-code/**`
- `marketplaces/claude-code/**`
- the Claude branch of `src/providers/session-start.ts`
- `tests/providers/claude-code/**`

Do not change Codex files or add future skills/agents.

## Required official contracts

- <https://code.claude.com/docs/en/plugins-reference>
- <https://code.claude.com/docs/en/plugin-marketplaces>
- <https://code.claude.com/docs/en/hooks>

## Implementation contract

- Add `.claude-plugin/plugin.json`, `hooks/hooks.json`, and `skills/nttask/SKILL.md`.
- The installed invocation is `/neotolis-workflow:nttask`.
- SessionStart reads native hook JSON and supplies canonical `claude:<session_id>`, cwd, and absolute installed CLI path.
- Use `${CLAUDE_PLUGIN_ROOT}`; installed files cannot reference paths outside the plugin.
- SKILL implements the complete `NTTASK.md` behavior: empty invocation, direct source handling, primary scouting, focused questions, BRIEF gate, CLI error narration, and no automatic `ntgrill` start.
- Missing optional scout never blocks primary scouting.
- Include only `nttask`, identity hook, and runtime files.

## Acceptance

`TB-AC-08` is complete when a clean isolated Claude configuration can validate, install, list, and locate every necessary component without a model call.

## Verification

```powershell
npm run build
node scripts/run-tests.mjs provider-claude
```

The isolated harness must execute:

```text
claude plugin validate <staged-marketplace>
claude plugin marketplace add <staged-marketplace> --scope user
claude plugin install neotolis-workflow@neotolis-local --scope user
claude plugin list --json
```

Expected:

- validation and installation exit `0`;
- installed inventory contains exactly the intended skill/hook/runtime;
- the namespaced skill is discoverable;
- recorded SessionStart yields the exact native owner and existing CLI path;
- invalid/missing identity fails before project mutation.

## Handoff

Report commit, marketplace path, installed inventory, hook evidence, verification, deviations, and blockers. Stop.
